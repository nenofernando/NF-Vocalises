# NF Vocalises

Lista de vocalizes do app **NF Vocal Trainer** (By Neno Fernando - NF Audio Tools).
O app baixa `vocalises.json` ao abrir; para adicionar um vocalize, inclua um item em `vocalises` e envie ao GitHub.

Cada item: `id` (único), `title`, `description`, `bpm`, `step` (semitons entre rodadas),
`pattern` = lista de `[semitons acima da nota-base, duração em tempos]`.
